# Приложение для Благотворительного фонда поддержки котиков QRKot

## Описание проекта

Фонд собирает пожертвования на различные целевые проекты: на медицинское обслуживание нуждающихся хвостатых, на обустройство кошачьей колонии в подвале, на корм оставшимся без попечения кошкам — на любые цели, связанные с поддержкой кошачьей популяции.

### Основные возможности:

- Создание проектов
    
- Создание пожертвований и их распределение по проектам
    
## Стек технологий

- **Python 3.9**
    
- **Sqlalchemy 2.0**

- **Postgres**

- **Fastapi**

- **Fastapi-users**

- **Pydantic**

- **Aiogoogle**


    

## Установка и запуск

- Клонируем проект из удаленного репозитория

```git clone git@github.com:SavageDevfox/QRkot_spreadsheets.git```

- Переходим в склонированный проект

```cd QRkot_spreadsheets```

- Для установки вируального окружения 

```python -m venv venv```
```. venv/Scripts/activate```


- Для установки зависимостей ```pip install -r requirements.txt```

- Для применения миграций ```alembic upgrade head```

- Для запуска приложения ```uvicorn app.main:app```
